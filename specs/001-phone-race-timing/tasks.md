## Dependencies and parallel opportunities

Setup → foundation → US1 simulator → US2 virtual heat and panel → US3 reviewed apply → browser pilot. Complete and demonstrate US1 independently before physical devices enter the workflow. US2 can be verified entirely with virtual events. US3 can be verified with fixture heats and virtual lane submissions.

- **US1** — T005 and T006 cover separate test files. T007 supplies the readiness logic used by T008 and T009.
- **US2** — T010 and T012 can run together. T013 and T014 can proceed independently once they have their prerequisites.
- **US3** — T015 and T016 can run together. T017–T019 integrate their results.
- **Pilot** — T020 and T021 can run together against the same contract. Run field measurements after the desk listener and client work together.

## Implementation strategy

Deliver the single-computer simulator first, then apply reviewed virtual results to a real JAuswertung heat. Add the local browser pilot once both are verified. Use its measurements to decide whether the native-app follow-up is warranted.
